| 2026-11-09 | Action safety: legacy `confirm` | HTTP tools and MCP servers had `confirm` (default true). | 2026-11-09 | Action safety: taint scope | How long is a conversation "tainted" after outside text is read? | Until the history expires (600 s idle). | 2026-11-09 | Action safety: skill scope | When is a skill "active" for its allow-list? | When the user's words name it (whole words, any case) in that turn. A follow-up turn that does not name it has no scope. Endpoint-to-skill mapping and a per-scope tier ceiling are not built (P1-5). | open |
| 2026-11-09 | Action safety: yes and no words | Which utterances count as yes or no? | The existing strict yes list (plain yes, sure, go ahead, "send it"...) moved from the inbox tool to `session.rs`; a no list (no, cancel, stop, never mind, don't...) discards the action with "Okay, I won't do that." Anything else, including "yes but...", discards it and the turn continues. | open |
